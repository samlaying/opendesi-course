## 页面清单（签字版）

**视图 1 · 今日**（默认落地）
- 顶部：日期行 + 左右切换（只能切到过去，=补记入口）
- StatTile ×2：今日打卡状态、当前连续天数
- 条目列表：EntryRow（动作 / 重量×组数 / 补角标）；空态 =「还没有记录」+「记第一笔」
- 主按钮「+ 记一笔」（唯一 primary）
- 底部 tab：今日 / 月视图

**视图 2 · 记一笔**（表单，从主按钮进入）
- Segmented：部位 8 选 1
- 动作：该部位常用动作 chips + 自定义输入
- 明细行：重量(kg) × 组数，可加多条
- 保存（primary）= 写入所选日期并打卡；取消 = 文字按钮

**视图 3 · 月视图**
- 月份切换（过去/当月）
- 7 列点阵：checked/backfill/empty/future 四态；今天描边
- 统计行：本月 X 次 · 当前连续 Y 天 · 最长 Z 天
- 点任意过去日 → 跳回该日「今日视图」（查看/补记）
