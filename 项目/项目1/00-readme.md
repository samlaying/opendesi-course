## 为什么做

- 要解决的问题：练完懒得记（备忘录太糙），坚持没反馈（看不见连续性）
- 不做的原因（这次明确不做）：账号/云同步/社交/AI 建议——见 [03-product-context.md](03-product-context.md) 非目标

## 给谁

- 主用户：健身房/居家自练、每周 2~5 练的人（自己就是第一个用户）
- 不是给谁：教练管理学员、竞技数据分析、健身房商户

## 第一版做什么

- 必须有的 1 条主路径：打开 → 记一笔（部位/动作/重量×组数）→ 打卡成功 streak+1
- 第一版页面（最多 3 个）：① 今日+记录入口 ② 记一笔表单 ③ 月视图回看
- 成功时别人能打开什么：一个网页，离线可记、数据可导出 JSON
