# 第5章 让 Agent 从需求走到产品设计

**核心问题：** 有了 Product Context 和 Design System 之后，如何真正让 Agent 做设计：页面结构、视觉、完整 Prototype。

**上一章接口：** 两份资产必须已经存在，禁止从零 Vibe。  
**下一章接口：** 本章停在可讨论的 Prototype；可运行、可部署留给第6章。

## 一页概念

顺序锁死，不准跳步：

1. 读 Context（做什么）  
2. 读 DS（做成什么样）  
3. 只输出页面清单 + 跳转 + 每页状态  
4. 人验收结构  
5. 再生成 Prototype（HTML 或设计稿）  
6. 对照 DS 改，不另起一套风格  

对照测试（作业要求）：同一 Context 跑两遍——无 DS / 有 DS——交页面清单和截图差异。
